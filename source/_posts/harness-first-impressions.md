DeepSeek 昨天发布了 Harness 的开发者预览版，一个开源智能体框架，口号是"一切皆插件"。看了下介绍感觉挺有意思，第一时间装来试试，记录一下初体验。

## 它是什么

Harness 是 DeepSeek 出的开源智能体框架，项目在 [GitHub](https://github.com/deepseek-ai/deepseek-harness) 上开源，MIT 协议，官网是 <https://www.deepseek.com/harness/>。

```sh
npx @deepseek-ai/dsh web
```

默认会在本地起一个 Web UI，地址 `http://127.0.0.1:3080`。

它的核心理念是"一切皆插件"：模型、工具、技能、会话、沙箱、子代理，整个智能体的每个环节都可以换成插件。

## 初体验

跑起来之后先配置模型 API Key，然后选工作区，就可以开始对话了。下面说说印象比较深的几点。

### 图形化 Web UI

Harness 直接给了一套 Web 界面，会话、文件、任务状态都很清晰。

输入框的细节：智能体运行时按 Enter 的行为可以单独设置（比如繁忙时 Enter 排队发送还是直接插话），Cmd/Ctrl+Enter 是另一套行为。

### 轨迹视图

会话窗口里有个"轨迹"视图，把一次任务里每一轮、每一步（用户消息、助手回复、工具调用、子代理）都按时间列成一张表。点开某条记录能看到 token 用量、耗时、输入输出。

### 提问功能

这点是印象最深的：遇到需要做决定的地方，它不会自己擅做主张，而是停下来出现一个提问，弹出几个选项让我选。

<img src="https://img.vemiy.com/img/a07d6f7e-322d-4a54-ae8a-b2d110d31f31.webp" alt="dsh的提问功能" width="950" height="402">

### 配置模型

除了官方模型以外，设置里还有"添加提供方"，可以选一些预设的提供方，比如选择 opencode-go，直接填上 API Key 就能用；想接别的模型，也有"添加自定义提供方"，基本上能接入市面上所有模型。

### Agent 预设

内置了几套预设可以换：标准模式功能完整（文件编辑、Shell、检索、子代理、工作流都有）；极简模式只留两个工具，省 token 干简单活；PTC 模式是让模型不再一个动作调用一次工具，而是让模型写一个 TypeScript 程序，一次性把多步操作做完，不用好几轮往返，节省 token；创造模式是用来自己捏预设的，你可以根据你的工作内容让它自己给自己捏一个预设，这样减少了以前复杂的配置操作。

### 对话里直接输斜杠命令

输入框里敲 `/` 会弹出命令菜单，常用的有：`/plan` 进入或退出计划模式、`/goal` 设置长任务的目标、`/compact` 压缩旧对话省上下文、`/feedback` 给会话打分反馈、`/permission` 切换权限预设、`/export` 导出会话记录。

### 多子代理并行

比较大的活可以拆给子代理去跑，而且能同时跑好几个：每个子代理有独立的上下文，互不干扰，主对话只收结果，不会被各路的中间过程淹没，效率很高。

### 一切皆插件

"一切皆插件"是整个框架的架构：模型、工具、技能（skill）、会话、沙箱、子代理，甚至设置界面本身都是插件。也就是说没有任何东西是写死的内置功能——你用的每个环节都可以被替换、被改造。想换模型、加能力，不用等官方更新，装个插件或者直接改配置就行。

不过这样同时也带来了不稳定因素：插件改的是框架本身的每一环，自由度高的另一面是插件之间可能互相不兼容，或者改坏了整个系统直接崩掉。

## 总结

整体用下来，谈不上惊艳，但新鲜感十足。目前阶段的稳定性还是比较差的，运行一个长任务对话可能会崩掉，某些地方还透着草台班子味。但"一切皆插件"这个思路确实是一个创新所在，把整个框架的每一环都拆成可更改可替换的插件。官方说现在处于快速迭代期，以后会出现破坏兼容性的变更，所以未来可期吧。
